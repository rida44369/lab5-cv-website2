# Interactive CV Website

## Project Description
This project is a single-page interactive CV website created using HTML, CSS, and JavaScript. It presents personal information, education, career objectives, skills, courses, languages, and contact details in a clean and professional layout.

## Features
- Profile section with a profile picture.
- Eight clickable sections.
- Interactive navigation without opening a new page.
- Hover effects on navigation cards.
- Responsive and user-friendly design.
- Professional color scheme.

## Technologies Used
- **HTML5:** To structure the website.
- **CSS3:** To style the website and create hover effects.
- **JavaScript:** To switch between CV sections.

## How to Run
1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Make sure all project files and the profile image are in the correct locations.
4. Open `index.html` in a browser to view the website.
